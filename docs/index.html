Projects

Flying Cat on FPGA

Digital design · SystemVerilog RTL · DE10-Lite

A Flappy Bird-inspired game built as a digital circuit in SystemVerilog RTL for the DE10-Lite. It draws an animated cat over parallax scenery with a day/night cycle on VGA, detects collisions pixel by pixel, and speeds up its randomized pipes as the score climbs. While playing, the world floods and the controls switch to swimming and diving. Physics-based movement, scoring, and synchronized audio are all built in hardware.

Multithreaded web server

Systems programming · C, pthreads · Linux

A single-threaded C web server rebuilt as a concurrent one: a pthreads worker pool fed by a bounded FIFO request queue, with writer-priority synchronized logging.

Randomized group testing

Algorithms research · Published at SWAT 2020

Co-authored with Prof. Nader H. Bshouty: an adaptive randomized algorithm that determines the exact number of defective items, with a test count proven optimal up to small additive terms. Read the paper

Digital design in SystemVerilog

Digital design · SystemVerilog RTL

Designed and verified RTL for a 64-bit ALU and FSM-based control systems, including traffic-light controllers.

Heart-rate estimation from video

Signal processing · MATLAB

Estimates heart rate from a phone video of a fingertip: it averages the red channel of every frame, applies a 0.5–3 Hz band-pass filter, and counts the beats. The recording shown comes out at about 96 BPM.
